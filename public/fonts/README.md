# Brand fonts

Upload these files here (keep the exact names):

- `PlateGothicThreeFour.woff2` (or `.woff` / `.otf`) — headings
- `GlacialIndifference-Regular.woff2` (or `.otf`) — body text
- `GlacialIndifference-Bold.woff2` (or `.otf`) — bold body text
- `GlacialIndifference-Italic.woff2` (or `.otf`) — homepage headline (italic)

Glacial Indifference is free to download. Plate Gothic Three Four must be
used under a licence that allows web embedding; check before uploading.
Until the files are added, the site falls back to similar system fonts.
